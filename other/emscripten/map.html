DDNet Map Viewer

This draws a DDNet map the way the game draws it, and nothing else. It needs no fonts, no skins and no game images, only the map and the pictures the map names, so it is the quickest of these pages to start.

You can drop a .map file here, or click to select one. A map can also be named in the address, as map.html#map=<url>, and is then shown right away.
